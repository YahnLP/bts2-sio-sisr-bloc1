## Partie A – Inventaire des traceurs (≈ 25 min)

Le portail comprend les éléments suivants. Pour chacun, indique : **traceur ou non**, **exempté ou soumis au consentement**, **pourquoi**.

| N° | Élément du portail | Traceur ? | Consentement ? | Pourquoi |
|---|---|---|---|---|
| 1 | Cookie de session PHP après connexion d'une association | | | |
| 2 | Mémorisation du choix « Refuser » sur le bandeau | | | |
| 3 | Plan d'accès fourni par un service tiers, qui dépose ses propres cookies | | | |
| 4 | Bouton « Partager sur un réseau social » qui charge un script du réseau | | | |
| 5 | Journal d'accès du serveur (adresse IP, page, date) | | | |
| 6 | Choix d'un affichage « grands caractères » demandé par l'utilisateur et mémorisé | | | |

**J'anticipe.** Combien d'éléments sur six nécessitent un consentement ? ______

<details markdown="1">
<summary>Éléments de réponse</summary>

Éléments 3 et 4 : consentement. Éléments 1, 2 et 6 : exemptés (session, mémorisation du choix, personnalisation demandée). Élément 5 : ce n'est **pas un traceur** (rien n'est écrit sur le terminal de l'utilisateur) mais l'adresse IP est une **donnée personnelle** : il relève du registre, de la durée de conservation et de l'information, pas du bandeau.

</details>

## Partie B – Critiquer un bandeau (≈ 25 min)

Ouvre `bandeau_non_conforme.html`.

1. Liste **au moins cinq** défauts au regard du cours (information, choix, équilibre des boutons, moment du dépôt, retrait).
2. Pour chaque défaut, propose la **correction**.
3. Lequel est le plus grave ? Pourquoi ?

**J'anticipe.** Quel défaut te paraît visible dès l'ouverture de la page ? Lequel n'est visible qu'en lisant le code ? ______________________

<details markdown="1">
<summary>Éléments de réponse</summary>

Le cumul d'une acceptation implicite, d'un refus caché, d'un cookie déposé et d'une carte chargée **avant** tout choix, et de l'absence de retrait, rend le consentement invalide.

</details>

## Partie C – Faire passer le test (≈ 30 min)

1. Dans un dossier, place `consentement.js`, `consentement_fragment.html` et `test_consent.js`. Installe `jsdom` : `npm install jsdom`. Lance `node test_consent.js`.
2. Lis `consentement.js` : retrouve **où** la carte est créée, **où** le choix est mémorisé, **où** il est retiré. Complète : quelle fonction est appelée au chargement ? ______
3. **Casse** le programme : dans la fonction `appliquer`, remplace la ligne `if (choix === "accepte") afficherCarte(); else retirerCarte();` par un simple `afficherCarte();` (la carte se charge alors quel que soit le choix). Relance le test : quelle vérification échoue ? ______ Remets le code en l'état.
4. Écris, **à la main**, un test supplémentaire (deux lignes) qui vérifie qu'un clic sur « Refuser » après « Accepter » **retire** la carte.

**J'anticipe.** Quel message d'erreur affichera le test quand tu casseras le code ? ______________________

<details markdown="1">
<summary>Éléments de réponse</summary>

Après modification, l'assertion « pas de carte avant choix » échoue (message `pas de carte avant choix`). La fonction appelée au chargement est `appliquer(lireChoix())`. Un test de plus : après `accepter` puis `refuser`, `document.querySelectorAll("iframe").length` doit valoir 0.

</details>

## Partie E – Deux situations (≈ 25 min)

**E1. Demande d'effacement.** Le président d'une association écrit au courriel du portail : « Supprimez toutes mes données, y compris mes réservations passées. » Il y a deux réservations de l'an dernier et une réservation à venir dans six semaines.

1. Que fais-tu **dans l'heure** ? Que ne fais-tu **pas** seul ? ______
2. Que dois-tu vérifier avant toute suppression ? ______

**E2. Fuite.** Une agente envoie par erreur le tableau des réservations du mois (noms, téléphones, courriels de 14 personnes) à un destinataire extérieur à la commune. Elle te prévient à 16 h 10 le mardi.

1. Écris les **cinq premières actions** dans l'ordre. ______
2. À partir de quand le délai de notification éventuelle à la CNIL est-il décompté, et qui décide de notifier ? ______
3. Calcule la **date et l'heure limites** si le délai est de 72 heures à compter de 16 h 10 le mardi. ______

<details markdown="1">
<summary>Éléments de réponse</summary>

À contrôler : **alerte du délégué**, vérification d'identité, pas de suppression de la réservation à venir sans décision, trace écrite, calcul exact du délai.

</details>
