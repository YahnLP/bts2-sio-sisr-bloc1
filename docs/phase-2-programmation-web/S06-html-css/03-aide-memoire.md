# Aide-mémoire – HTML et CSS

*BTS SIO SISR 2e année – Bloc 1 – S06*

> Un mot ou un sigle inconnu ? Passe la souris dessus, ou ouvre le [glossaire](../../ressources/glossaire.md).

## Squelette

`<!DOCTYPE html>` · `<html lang="fr">` · `<meta charset="utf-8">` · `<meta name="viewport" ...>` · `<title>` · `header`, `nav`, `main`, `section`, `footer`.

## Formulaire

`label for` = `id` du champ · `name` = nom envoyé au serveur · types : `text`, `email`, `date`, `time`, `number` · `required` ne protège pas le serveur.

## CSS

`sélecteur { propriété: valeur; }` · `box-sizing: border-box` · `display: flex` · `var(--nom)` · `@media (max-width: 600px) { ... }`.

## Accessibilité

Contraste **≥ 4,5:1** · clavier (Tab) · focus visible · `alt` · pas d'information par la couleur seule · un `h1`, titres sans saut.

## Outils (F12)

Inspecteur · mode adaptatif · console · réseau.
