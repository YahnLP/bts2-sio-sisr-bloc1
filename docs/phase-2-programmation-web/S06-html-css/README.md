> [!NOTE]
> **Question qui guide la séance :** *« Une page web, c'est du texte : comment le navigateur sait-il ce qui est un titre, un tableau, un formulaire, et à quoi cela doit ressembler ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Écrire** une page HTML structurée avec les balises sémantiques
2. **Construire** un tableau et un formulaire accessibles
3. **Mettre en forme** avec CSS (boîte, flex, variables, adaptation à l'écran)
4. **Vérifier** le contraste et la navigation au clavier
5. **Utiliser** les outils de développement du navigateur
