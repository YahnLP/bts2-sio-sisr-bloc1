# Aide-mémoire – Contrôle et fonctions

*BTS SIO SISR 2e année – Bloc 1 – S08*

> Un mot ou un sigle inconnu ? Passe la souris dessus, ou ouvre le [glossaire](../../ressources/glossaire.md).

## Structures

`if / else if / else` · `for`, `while`, `forEach` · `some`, `filter`, `map`, `reduce`.

## Fonction

`function nom(parametres) { return valeur; }` · courte · pure si possible · nom explicite.

## Chevauchement

`a.debut < b.fin && b.debut < a.fin` (comparaisons **strictes** : bout à bout = pas de chevauchement).

## Test

`assert.strictEqual(obtenu, attendu)` · cas limites · un test qui échoue après changement = **régression**.

## Formules

Taux d'occupation = temps réservé / temps ouvert.
