| **Durée** | 4 heures |

| **Compétences travaillées** | B1.4 (voir [le référentiel](../../ressources/referentiel.md)) |

> [!NOTE]
> **Question qui guide la séance :** *« Le planning est écrit : comment le faire vivre, à plusieurs, sans le perdre dans un fichier ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Citer** les fonctions d'un outil de gestion de projet
2. **Paramétrer** un outil : états, équipe, droits, notifications
3. **Saisir** un projet, ses tâches, ses dates et son équipe
4. **Calculer** et suivre l'avancement du projet
5. **Relier** les demandes du support (tickets) au projet
