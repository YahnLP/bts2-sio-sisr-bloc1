## Avant d'utiliser

États · types · équipe et rôles · droits par profil · notifications · conventions de saisie.

## Avancement

*Σ (charge × % réalisé) / Σ charges.* Palier 0, 25, 50, 75, 100 ; « terminé » = livrable validé.

## Tableau de bord

Délai (chemin critique) · budget (charge consommée / prévue) · qualité (anomalies ouvertes).

## Réflexes

- Les **menus changent** selon la version : repérer les notions.
- Un **ticket** lié au projet montre le coût réel.
- Vérifier soi-même les **dépendances** si l'outil ne le fait pas.
- Un point d'avancement donne : **chiffre, écart, décision**.
